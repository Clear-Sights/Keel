# Small-Tools ranking (gen1)

Tier rule: COMPUTABLE FROM THE GRADES PLUS TWO GREPS -- no taste anywhere in it.

INPUTS (per seat):
  R = number of the 8 sibling repos (Keel, Ward, Makoto, Rung, Discontinuity, Courthouse,
      gyroscope-dev, Causality) in which the seat surfaced >=1 confirmed non-noise finding
      about that repo's own committed artifacts.  Counted from the seat's grade `real_hits`,
      de-duplicated by repo, excluding Small-Tools itself, scratch subjects, planted defects,
      and findings that are about the tool rather than the subject.
  P = 1 if the seat takes its subject as an argument or environment variable and ran
      unmodified against at least one sibling; else 0.
      Computed: `grep -oE 'add_argument\("[^"]+"' SEAT.py` for Python seats
      (P=0 iff the only arguments are flags like --self-test), `grep -oE '\$\{[A-Z_]+:-' SEAT.sh`
      for shell seats.  Measured P=0 for exactly two seats: bench
      (`usage: bench.py [-h] [--self-test]`) and reaper (no --root; the subject is whichever
      repo contains the script).
  F = refinement, 1-10, from the seat's grade.
  B = count of flaws whose text begins "break:".
  W = count of flaws whose text begins "weakness:".   (flaws beginning "nit:" are ignored)

SCORE:
  score = 3*R + 2*P + F - 2*B - W

TIER:
  A  if R >= 3 and score >= 10      -- reach for it first; it has paid on three or more repos
  B  if R >= 1 and score >=  3      -- keep, after closing the named breaks
  C  if R >= 1 and score <   3      -- the question is real, this instrument is not; fold or skill
  D  if R == 0                      -- found nothing anywhere it was pointed; retire the script

RANK:
  sort by (tier A<B<C<D, then score descending, then R descending, then B ascending)

WHY THESE CUTS: R is first because the owner's complaint is that the seats are unused, and a
seat that has never found anything in a repo he owns has no evidence of usefulness whatever its
self-test says -- measured, four seats sit at R=0 (bench, blindspot, plothole, subject) and all
four are retired.  Breaks are weighted -2 because a break is a wrong answer, and a tool that
answers wrongly is worse than no tool: codex-herd reported LANDED for a commit merged nowhere,
container-anchor's checkin reported 'pushed' with zero bundles written, blindspot flipped
FAIL->PASS when non-defect commits were added.  P is weighted +2 because a seat that cannot be
pointed at a subject cannot accumulate R at all, which is exactly why bench and reaper score as
they do.  Note the rule is honest about its own limits: a seat whose subject is LIVE STATE rather
than a committed artifact (container-anchor) has an R that changes hour to hour -- re-measured
read-only today, 7 of 8 siblings MATCH their pushed head and 1 refuses, against 5 hits at grading
time -- so it is scored at its durable value and the variance is stated rather than averaged away.

## skills
- commit-history-reading (absorbs blindspot + subject; both scripts retire). One `git log` corpus, two readings a model does natively and a regex measurably cannot: (a) does each commit subject name the work, or only the act of committing -- the judgement that reads 'checkpoint 2332' as naming nothing and 'fix the retry backoff on a closed socket' as naming work, where subject.py scored 0 findings over 1,328 sibling commits with 14 uncaught in Causality alone; (b) do the defect commits cluster into families the taxonomy still explains, ALWAYS printing the unclassified share beside the families and never widening a pattern to swallow its residue -- the discipline blindspot states and its own regexes violate (90 Causality commits filed under 'one-sided-local' on the substring 'reachab' from 'reachability index'). Refusal rule carried over: an empty history is not a clean one.
- prose-earning-its-place (absorbs plothole + grounding; both scripts retire). One reading pass over one document, answering plothole's four questions by meaning rather than by backtick count -- a block that spends words producing nothing openable (stone), a marker naming nothing (leak), duplicated prose (twin), length without content (creep) -- and grounding's two: does the reader holding only this document resolve every referring expression, and does every number, flag and path name its basis. Carries the measured negative controls so the taxonomy is not applied blindly: a hero image, a bold one-line thesis, a blockquote tagline and the Apache-2.0 licence are NOT stones, and an antecedent in the same or preceding sentence is NOT unresolved. Never propose `cut` as a default.
- landing-and-anchoring (the non-scriptable half of the land fold; container-anchor's init/checkin/recover and codex-herd's dispatch/flaw-gate retire into it). The ORDER and the REFUSAL DISCIPLINE, which is procedure and not computation: gate before commit and never accept a command that merely exits 0 as a gate; never `git add -A` -- commit named paths, not whatever the gate wrote; prove a land by ancestry, never by byte-equality of heads; never retry a rejection, only a network failure; pin a worker's launch to `git hash-object BRIEF` against a receipt whose required keys are all present, and treat a two-field hand-written receipt as no receipt; re-read the ops record at every wake before redispatching; and treat 'nothing to snapshot' as NOT-EVALUABLE, never as a successful check-in.
- ledger-and-cell-discipline (absorbs plan-ledger + bench's vocabulary; both scripts retire). Two rules that produce the records the surviving tools grade. (a) Cells: every preregistered dispatch earns exactly one of four states -- caught, missed, false-positive, NOT-EVALUABLE -- one state per dispatch, and an awkward cell may not leave the comparison by going silent; a flaky command is UNSTABLE, not a decided verdict. (b) Ledgers: three exhaustive dispositions, a receipt that is a real commit touching a named file of the row, corrections made by appending a new row that names the old one and never by rewriting, and Sigma that never rises. This is the skill that has to exist first, because `find` over all nine repos returns zero plan-ledger subjects -- nothing ever made anyone keep such a ledger.
- tool-report-triage (the second half of every surviving tool+skill seat). The adjudication step that decided the outcome in most measured applications and that no script here performs: name the authority and state its grammar BEFORE running cover; separate a tree's own first-party files from genuine third-party in a hermetic report (7/11 Ward, 6/16 Discontinuity, 10/34 Causality undeclared hits were the tree's own); choose the disarm DIRECTION for meta_test, because `return True` is backwards for a detector; tell a renamed section from a lost one in plan's output; tell real drift from two vocabularies that were never the same set in ratchet's stale/ungoverned halves; adjudicate reaper's candidate list one unit at a time and never run --apply on it unattended; answer readme's six questions on substance and reconcile against the script; and read a two-roads PASS for coverage, since 'the transform preserved behavior' and 'the corpus never reached the transform' print identically.
